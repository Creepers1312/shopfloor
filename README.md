# Shopfloor Board — Digitales Shopfloor Management

Deutsche Web-App für das digitale Shopfloor Management mit SQIDP-Board, Kennzahlen und Huddle.

## Nutzung

Die komplette App steckt in einer einzigen Datei: `index.html`. Einfach im Browser öffnen oder auf einem beliebigen Webserver (z. B. GitHub Pages, Nginx) ausliefern.
